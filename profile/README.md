## TeamShift open source

Free, open-source tools for people building and testing AI agents for small-business operations. Built by [TeamShift](https://teamshift.io/open-source?utm_source=github&utm_medium=org-profile), which runs AI workers for small businesses.

| Repository | What it's for |
|---|---|
| [**smb-sandbox**](https://github.com/teamshift-io/smb-sandbox) | A realistic, fully fictional small business for testing AI agents: a dataset generator, mock CRM/inbox/calendar/invoicing/phone MCP servers, and 10 verified business tasks graded on end state. |
| [**agent-toolkit**](https://github.com/teamshift-io/agent-toolkit) | Small, sharp dev tools: a workflow preflight linter, a webhook signature inspector, and an OAuth permission planner. |

Try the tools in your browser, no login: [teamshift.io/open-source](https://teamshift.io/open-source?utm_source=github&utm_medium=org-profile)

Contributions are welcome. Good first issues: add an industry, a kind of realistic mess, a workflow task, a lint rule, or a scope catalog correction.
